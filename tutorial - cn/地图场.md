## 核心概念

`Field` 是二维整数格点的容器，支持三种数据语义：
- **普通场**：存储成本值（0-254 可通行，255 障碍）
- **距离场**：BFS 计算的曼哈顿距离
- **方向场**：8 方向编码（1-8），指向最近目标

所有形态学操作默认 **原地修改**，返回 `self` 支持链式调用。

---

## 快速开始

```python
# 从二维数组创建（Screeps 地形数据）
field = Field(get.COST_ARRAY2D)
# field = Field(get.COST_MATRIX)  # 等价

# 获取到己方SPAWN的距离场
dist = field.toDistance(SPAWN)
dist.view()
```

**注意**：
  - get.COST_ARRAY2D 和 get.COST_MATRIX 是动态常量
  - 在tick = 0时等价默认地图数据。
  - 在tick = 1时才会更新各种阻挡效果。
---

## 核心功能

### 数据操作

**单元格读写**：`at(x: int, y: int, v: int = None) -> int | None`

最基础的操作。**读取**时返回格点值；**写入**时原地修改并返回 `None`。

**示例**：
```python
def init(k: GlobalKnowledge):
    DIST = Field(get.COST_ARRAY2D).toDistance(SPAWN)
  
# 对敌人按照靠近SPAWN进行排序
enemies = sorted(k.enemies, lambda e: DIST.at(e.x, e.y))
```
---

**区域填充**：`fill(x: int, y: int, w: int, h: int, v: int) -> None`

矩形区域批量赋值，原地修改。

---

### 场转换

**签名**：`toDistance(target: Point | int, y: int = None) -> Field`

BFS 计算每个格点到目标的最短步数。障碍（≥255）不可通行，未可达格点填充 `Field.DEFAULT`。

---

### `toMatrix` / `toMotion`

将 Field 转换回 Screeps 原生对象，用于最终路径规划。

**`toMatrix()`**：转 CostMatrix（限 100×100），供 `PathFinder.search` 使用  
**`toMotion()`**：转 MotionOptions，供 `creep.move` 使用  

---

### 可视化

**签名**：`view(layer: int = 1) -> bool`

在指定 layer 循环显示 33×33 区块。根据场类型自动显示数值或方向箭头。

**示例**：
```python
field.view()  # 每9tick完全展示一次地图
```

当完成一轮可视化后，返回 `True`，否则返回 `False`。

---

### 形态学

扩展或收缩障碍区域（值为 255 的格点）。

**`dilate()`**：膨胀——墙壁向 8 邻域扩展一格  
**`erode()`**：腐蚀——墙壁边缘收缩一格
---

### 对象拷贝：`clone`

**签名**：`clone() -> Field`

创建 Field 的深拷贝，返回新实例。

用于保存原始数据快照，避免原地修改的副作用。

## 附录：完整方法参考

| 类别       | 方法 | 功能                      |
|----------|------|-------------------------|
| **数据操作** | `at(x, y, v?)` | 读写格点值                   |
|          | `roi(x, y, w, h)` | 提取子区域为新 Field           |
|          | `fill(x, y, w, h, v)` | 矩形区域填充                  |
|          | `flood(x, y, v?)` | `None`=魔棒选区，数值=填充       |
| **场转换**  | `toEdges()` | 障碍边缘检测（255=边缘）          |
|          | `toDistance(target: Point \| int, y: int = None)`     | 普通场转距离场 |
|          | `toDirect(reverse?)` | 距离场转方向场（1-8）            |
|          | `toMatrix()` | 转 CostMatrix（限 100×100） |
|          | `toMotion()` | 转 MotionOptions 寻路选项    |
|          | `toPool(k, s, mode)` | 最大/平均池化， stride 可选      |
| **可视化**  | `view(layer?)` | 在指定 layer 显示 33×33 区块   |
| **形态学**  | `dilate()`, `erode()` | 膨胀/腐蚀（255 值） |
|          | `opening(k?)`, `closing(k?)` | 开/闭运算（先腐蚀后膨胀/反之） |
|          | `topHat(k?)`, `blackHat(k?)` | 顶帽/黑帽变换 |
| **梯度**   | `gradient(k?)` | 形态学梯度（max-min） |
|          | `gradientI(k?)`, `gradientEx(k?)` | 内部/外部梯度 |
| **滤波**   | `blur(kw, kh)`, `gaussBlur(kw, kh, sigma)`, `medianBlur(k?)` | 均值/高斯/中值模糊 |
|          | `bilateralFilter(d, sigmaColor, sigmaSpace)` | 保边平滑 |
| **边缘检测** | `sobel(dx, dy, ksize, scale, delta)`, `scharr(dx, dy)`, `laplacian(ksize)` | 标准卷积算子 |
| **射线检测** | `ray(pt0, pt1, threshold?)` | Bresenham 直线障碍检测 |
| **螺旋搜索** | `space(tx, ty, maxVal?, rot?)` | 寻找最近可用位置 |
| **数据拷贝** | `clone()` | 深拷贝 |
| **静态**   | `getStructuringElement(shape, kw, kh)` | 获取形态学内核 |


---

**注意**：所有 `ksize` 必须为正奇数。原地修改方法返回 `self` 支持链式调用。
