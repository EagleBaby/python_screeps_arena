### 绘图概述

本节将介绍如何用 `View` 在游戏画面上绘制图形。绘图是调试与可视化的好帮手：把爬虫的目标、路径、危险区域画出来，一眼就能看出逻辑是否按预期运行。

`View` 是对游戏内置 `Visual` 的封装（由 `builtin.view` 提供），按教程惯例写上 `from builtin import *` 后即可直接使用。它支持文字、线段、虚线、圆形、矩形、多边形，以及路径、血条、聚类等专用图形。

绘制只是给你看的，不会影响对局结果，也不会消耗能量，可以放心在正式代码里保留。

**注意**：同一图层反复绘制会不断叠加，因此持久化图层在每 tick 重画之前要先 `clear()`。

### 快速开始

```python
from builtin import *

V = View(3)                                   # 在图层 3 上绘图

def step(k: GlobalKnowledge):
    V.clear()  # > ignore                       # 先清空，再重画
    V.text('Hello', Point(5, 5), 0.5, '#FF0000')
    if k.enemies:
        V.circle(k.enemies[0], 0.4, '#FFA500')  # 圆心可以直接用 Creep
```

非持久化的图形只显示一个 tick，适合做一次性标记，不需要清空：

```python
View(99, False).circle(Point(10, 10), 0.4, '#FFA500')
```

**注意**：编译器可能对 `clear()` 提出警告，在行尾写 `# > ignore` 即可忽略。

### 坐标、图层与持久化

#### 坐标

所有坐标都以"格"为单位，`(0, 0)` 是地图左上角。整数坐标正好落在格子的中心，所以 `Point(10, 10)` 就是 x:10, y:10 那格的中心。

**注意**：矩形、文字这类以左上角或基线为锚点的图形，标记某一格时要偏移半格，例如 `Point(x - 0.5, y - 0.5)`。

所有绘图方法的坐标参数都接受任何带 `x`、`y` 属性的对象，`Point`、`Creep`、`Flag` 都可以直接传入，无需手动转换。

#### 图层与持久化

图层的数字越大，绘制的内容越靠上。建议给不同用途分配固定图层，避免互相遮挡，例如图层 3 画路径、图层 4 画标记。

| 参数名 | 类型 | 可选 | 默认值 | 描述 |
|-------|------|------|--------|------|
| `layer` | `int` | 否 | - | 图层编号，数字大的覆盖在数字小的上面 |
| `persistent` | `bool` | 是 | `True` | 是否持久化：`True` 时图形常驻，需手动 `clear()` 清除；`False` 时只显示当前 tick |

**示例**：在图层 4 上绘制常驻标记，图层 99 上绘制一次性标记

```python
G.flag_view = View(4)              # 持久图层，全局保存一份，每 tick 清空重画
View(99, False).circle(Point(10, 10), 0.4, '#FFA500')   # 只显示一 tick
```

### 绘制文字

**签名**：`text(text, pos, font, color, options = None)`

| 参数名 | 类型 | 可选 | 默认值 | 描述 |
|-------|------|------|--------|------|
| `text` | `str` | 否 | - | 文字内容，支持中文与 emoji |
| `pos` | `Point` | 否 | - | 文字位置（基线锚点） |
| `font` | `str` \| `int` \| `float` | 否 | - | 字号，`0.5` 表示按游戏坐标的 0.5 格，也可写 `'12px'` 或 `'0.7 serif'` |
| `color` | `str` | 否 | - | 字体颜色，如 `'#FF0000'` |
| `options` | `UsrObject` | 是 | `None` | 其他样式选项，见[样式选项](#样式选项) |

**示例**：在出生点上方显示实时信息

```python
V.text(f'敌人: {len(k.enemies)}', Point(SPAWN.x, SPAWN.y - 1), 0.4, '#FFFFFF')
```

### 绘制线段

#### 实线：line

**签名**：`line(pos1, pos2, width = 0.1, color = None, options = None)`

| 参数名 | 类型 | 可选 | 默认值 | 描述 |
|-------|------|------|--------|------|
| `pos1` | `Point` | 否 | - | 起点 |
| `pos2` | `Point` | 否 | - | 终点 |
| `width` | `float` | 是 | `0.1` | 线宽，单位为格 |
| `color` | `str` | 是 | `None` | 线条颜色，不填时是白色 |
| `options` | `UsrObject` | 是 | `None` | 其他样式选项，见[样式选项](#样式选项) |

**示例**：每 tick 刷新一条前线

```python
V.clear()  # > ignore
V.line(seg[0], seg[1], 0.2, '#FF0000')
```

#### 虚线：dashLine

**签名**：`dashLine(pos1, pos2, dashLength = 0.5, gapLength = 0.5, width = 0.1, color = None, options = None)`

参数与 `line` 相同，额外多出线段与间隔的长度控制：

| 参数名 | 类型 | 可选 | 默认值 | 描述 |
|-------|------|------|--------|------|
| `dashLength` | `float` | 是 | `0.5` | 每一段实线的长度 |
| `gapLength` | `float` | 是 | `0.5` | 实线之间的间隔长度 |

**示例**：画一条虚线表示"计划但未执行"的连线

```python
V.dashLine(Point(0, 0), Point(10, 10), 0.5, 0.5, 0.1, '#00FF00')
```

如果只是想要一条虚线边框，用 `options` 里的 `lineStyle` 更省事，见[样式选项](#样式选项)。

### 绘制形状

#### 圆形：circle

**签名**：`circle(pos, radius, fill = None, options = None)`

| 参数名 | 类型 | 可选 | 默认值 | 描述 |
|-------|------|------|--------|------|
| `pos` | `Point` | 否 | - | 圆心 |
| `radius` | `float` | 否 | - | 半径，单位为格（`0.5` 约等于半格宽） |
| `fill` | `str` | 是 | `None` | 填充色，不填时只画描边 |
| `options` | `UsrObject` | 是 | `None` | 其他样式选项，见[样式选项](#样式选项) |

**示例**：实心圆与空心圆

```python
View(99, False).circle(Point(10, 10), 0.4, '#FFA500')                     # 实心
V.circle(Point(10, 10), 0.5, None, {'stroke': '#FF0000', 'strokeWidth': 0.1})   # 空心
```

#### 矩形：rect

**签名**：`rect(pos, width, height, fill = None, options = None)`

| 参数名 | 类型 | 可选 | 默认值 | 描述 |
|-------|------|------|--------|------|
| `pos` | `Point` | 否 | - | **左上角**坐标 |
| `width` | `float` | 否 | - | 宽度 |
| `height` | `float` | 否 | - | 高度 |
| `fill` | `str` | 是 | `None` | 填充色，不填时为空心 |
| `options` | `UsrObject` | 是 | `None` | 其他样式选项，见[样式选项](#样式选项) |

**示例**：用空心方框标记一个格子

```python
# 标记 1x1 的格子：左上角偏移半格
V.rect(Point(TARGET_FLAG.x - 0.5, TARGET_FLAG.y - 0.5), 1, 1, None,
       {'stroke': '#98FB98', 'strokeWidth': 0.1})
```

#### 多边形：poly

**签名**：`poly(points, fill = None, options = None)`

| 参数名 | 类型 | 可选 | 默认值 | 描述 |
|-------|------|------|--------|------|
| `points` | `list[Point]` | 否 | - | 顶点坐标列表，至少 3 个点 |
| `fill` | `str` | 是 | `None` | 填充色，不填时为空心 |
| `options` | `UsrObject` | 是 | `None` | 其他样式选项，见[样式选项](#样式选项) |

**示例**：画一个三角形区域

```python
V.poly([Point(2, 2), Point(8, 2), Point(5, 8)], None,
       {'stroke': '#00BFFF', 'strokeWidth': 0.15})
```

### 绘制路径

**签名**：`path(pts, width = 0.2, color = None, options = None)`

| 参数名 | 类型 | 可选 | 默认值 | 描述 |
|-------|------|------|--------|------|
| `pts` | `list[Point]` | 否 | - | 路径点列表，依次连接，至少 2 个点 |
| `width` | `float` | 是 | `0.2` | 线宽 |
| `color` | `str` | 是 | `None` | 线条颜色，不填时使用默认主题色 `'#AEFC80'` |
| `options` | `UsrObject` | 是 | `None` | 其他样式选项，见[样式选项](#样式选项) |

与逐段调用 `line` 相比，`path` 会自动处理传送门：路径点经过传送门时，自动用虚线连到出口并继续绘制（虚线颜色由实线颜色推导，保证与实线能区分开）；若遇到尚未揭示的传送门，会在当前位置画一个红色叉号并结束绘制。

**示例**：绘制一个爬虫到目标点的路径

```python
V.path([creep, target], color='#FFA500')

# 含传送门的路径：creep -> 入口 -> 出口 -> 目标
V.path([creep, portalA, portalB, target])
```

### 绘制Creep标题

**签名**：`header(creep)`

在爬虫头顶绘制"名字 ❤️ 血量百分比"，颜色随血量变化，满血偏绿、血量越低越偏红。

| 参数名 | 类型 | 可选 | 默认值 | 描述 |
|-------|------|------|--------|------|
| `creep` | `Creep` | 否 | - | 要标注的爬虫 |

**示例**：给所有敌人标注血条

```python
for e in k.enemies:
    V.header(e)
```

### 绘制聚类结果

**签名**：`cluster(cluster, fill = None, options = None)`

把聚类结果画出来：用半透明方格标出集群覆盖的范围，并在集群中心逐行显示统计信息。显示内容由 `GlobalKnowledge` 上的 `draws` 开关控制：固定有一行 `grade`（等级），另外 `k.draws.cluster_sse`、`k.draws.cluster_density`、`k.draws.cluster_entropy` 为 `True` 时分别增加 `sse`、`density`、`entropy` 行。

| 参数名 | 类型 | 可选 | 默认值 | 描述 |
|-------|------|------|--------|------|
| `cluster` | `ClusterResult` | 否 | - | 聚类结果，例如 `k.clusters.enemies` 中的一项 |
| `fill` | `str` | 是 | `None` | 填充色，不填时使用默认主题色 |
| `options` | `UsrObject` | 是 | `None` | 其他样式选项，见[样式选项](#样式选项) |

**示例**：查看最大的一支敌军集群

```python
if k.clusters.enemies:
    V.cluster(k.clusters.enemies[0])
```

### 样式选项

所有绘制方法的最后一个参数都是 `options`，用来微调外观，常用的键如下：

| 选项 | 类型 | 说明 |
|------|------|------|
| `fill` | `str` | 填充色，如 `'#FF0000'` |
| `stroke` | `str` | 描边颜色，圆、矩形、多边形靠它画边框 |
| `strokeWidth` | `number` | 描边线宽，默认 `0.1` |
| `opacity` | `number` | 不透明度 0~1，画半透明区域时使用 |
| `lineStyle` | `str` | 线条样式：不填为实线，还可以是 `'dashed'`（虚线）或 `'dotted'`（点线） |
| `backgroundColor` | `str` | 文字背景色，`text` 专用，适合让文字在杂乱画面上依然清晰 |

**注意**：方法自带的参数（如 `color`、`fill`、`width`）优先级高于 `options` 中的同名键。

**示例**：半透明的黄色区域 + 带背景的文字

```python
V.rect(Point(3.5, 3.5), 5, 5, '#FFFF00', {'opacity': 0.3})
V.text('危险区', Point(6, 6), 0.5, '#000000', {'backgroundColor': '#FFFF00', 'opacity': 0.9})
```

### 在CreepLogic中绘图

如果绘图内容属于某个爬虫（比如它的目标、它的巡逻路线），可以让 `CreepLogic` 自动管理一个 `View`，不必自己创建和清空：

| 类变量 | 类型 | 默认值 | 描述 |
|-------|------|------|------|
| `DRAW` | `bool` | `False` | 是否启用绘制 |
| `LAYER` | `int` | `10` | 绘制使用的图层 |

开启 `DRAW` 后，每 tick 逻辑步进的最后会自动调用 `onDraw`，并传入已经绑定好该图层的 `View`：

| 参数名 | 类型 | 可选 | 默认值 | 描述 |
|-------|------|------|--------|------|
| `c` | `Creep` | 否 | - | Creep实例 |
| `v` | `View` | 否 | - | 当前逻辑专用的视图 |
| `k` | `GlobalKnowledge` | 否 | - | GlobalKnowledge全局知识 |
| `*refs` | `CreepLogic` | 是 | - | 由link创建的子实例 |

**示例**：画出爬虫的血量标题与到目标的路径

```python
class HunterCreep(CreepLogic):
    NAME = "Hunter"
    DRAW = True                     # 启用绘制
    LAYER = 11                      # 绘制图层

    def onDraw(self, c: Creep, v: View, k: GlobalKnowledge):
        v.header(c)
        if self.target:
            v.path([c, self.target], color='#EE6363')
```

和 `onStep` 一样，用不到的参数可以直接省略：

```python
def onDraw(self, c, v):  # 不会导致错误
    v.circle(c, 0.4, '#FFA500')
```

### 方法速查

| 类别 | 方法 | 功能 |
|------|------|------|
| **创建与清理** | `View(layer, persistent?)` | 创建视图 |
| | `clear()` | 清空当前图层 |
| **基础图形** | `text(text, pos, font, color, options?)` | 文字 |
| | `line(pos1, pos2, width?, color?, options?)` | 线段 |
| | `dashLine(pos1, pos2, dashLength?, gapLength?, width?, color?, options?)` | 虚线 |
| | `circle(pos, radius, fill?, options?)` | 圆形 |
| | `rect(pos, width, height, fill?, options?)` | 矩形（`pos` 为左上角） |
| | `poly(points, fill?, options?)` | 多边形 |
| **专用图形** | `path(pts, width?, color?, options?)` | 路径（自动处理传送门） |
| | `header(creep)` | 爬虫血量标题 |
| | `cluster(cluster, fill?, options?)` | 聚类结果 |
| **其他** | `color` | 每次读取都返回一个不同的颜色，方便给多个对象分别上色 |
| | `size()` | 返回当前视图已存储的绘制数据大小 |

### 最终代码

以下示例每 tick 重画一次战场信息：静态标记画在持久图层上，动态连线与血条随战况刷新。

```python
from builtin import *

SPAWN = get.spawn()
V = View(3)                                  # 持久图层 3，全局创建一次

def init(k: GlobalKnowledge):
    """开局：画一次静态标记"""
    V.clear()  # > ignore
    for i, flag in enumerate(get.flags()):
        V.rect(Point(flag.x - 0.5, flag.y - 0.5), 1, 1, None,
               {'stroke': '#98FB98', 'strokeWidth': 0.1})
        V.text(f'F{i}', Point(flag.x, flag.y), 0.4, '#98FB98')

def step(k: GlobalKnowledge):
    """每 tick：清空后重画动态信息"""
    V.clear()  # > ignore
    for e in k.enemies:
        V.header(e)                          # 名字 ❤️ 血量
        V.path([SPAWN, e], color='#FF0000')  # 敌人到出生点的路径

    if k.enemies:
        # 非持久化视图：只显示一 tick 的标记
        View(99, False).circle(k.enemies[0], 0.4, '#FFA500')
```

**注意**：绘制二维场数据（成本场、距离场、方向场）请使用 `Field.view()`，详见 [地图场.md](./地图场.md)。
